# 미션 가챠

미션을 완료하면 점수가 쌓이고, 점수가 기준치에 도달하면 뽑기권이 생겨 가챠를 뽑을 수 있는 웹앱입니다.
팀(6) → 구역(팀당 5) → 구역원(구역당 약 10명) 구조를 그대로 반영했습니다.

## 로컬 실행 방법

```bash
npm install
npm run seed   # 데모 데이터 생성 (6팀 x 5구역 x 10명, 미션 12개, 가챠 아이템 9종)
npm run dev    # http://localhost:3000
```

DB 연결은 `DATABASE_URL` 환경변수로 설정합니다 (Postgres). 로컬에서 테스트하려면
`.env` 파일을 직접 만들어 아래처럼 채워주세요 (Claude가 대신 만들 수 없는 파일입니다):

```
DATABASE_URL="postgresql://..."
```

## 로그인

- 팀 → 구역 → 이름 선택 + PIN 번호로 로그인합니다 (이메일/비밀번호 회원가입 없음).
- 데모 구역원 PIN: `1234`
- 관리자(박용운) PIN: `0000`

## 구조

- **파트**: 구역원은 직장인 / 대학생 / 휴학·취준생 중 한 파트에 속하고, 자기 파트 미션 + 명절 미션(공통)을 봅니다.
- **구역원**: `/zone`에서 미션 체크, 구역 총점·참석률 확인. 미션당 10점(어려운 것 20점).
- **뽑기(구역 통합)**: 구역 점수가 100점 쌓일 때마다 구역 뽑기권 1장. **구역장이 대표로** `/gacha`에서 뽑고,
  결과 화면의 "결과 링크 복사"로 카톡방에 공유합니다 (`/result/<id>` 링크는 로그인 없이 열립니다).
  상품은 구역 전체가 함께 쓰는 대화거리(심리테스트 링크 등)입니다.
- **관리자**: `/admin` 전체 현황(팀·구역 참석률 표, 차트, 팀→구역→구역원 드릴다운, 구역원 화면 표시 설정),
  `/admin/org` 조직 관리(팀/구역/구역원·파트 지정), `/admin/missions` 파트별 미션 관리 + 마감 기한,
  `/admin/gacha` 가챠 아이템·확률·링크 관리 + 테스트 뽑기 + 무제한 뽑기 미리보기.

## 뽑기권 산정 방식

미션마다 점수(기본 10점, 어려운 것 20점)가 있고, 구역원 전원의 점수를 합친 **구역 총점**이
"뽑기권 전환 기준"(기본 100점)에 도달할 때마다 구역 뽑기권이 1장 생깁니다.
기준은 `/admin/gacha`에서 바꿀 수 있습니다.

## 미션 마감 기한

`/admin/missions`에서 날짜/시간을 지정하면, 그 시각이 지난 뒤에는 구역원이 미션을
체크/취소할 수 없습니다 (서버에서도 강제됩니다). 비워두면 마감 없이 계속 진행됩니다.

## 실제 명단 반영

지금은 데모용 무작위 인원 데이터가 들어있습니다. 실제 팀/구역/구역원 명단이 준비되면
`/admin/org`에서 하나씩 추가하거나, `prisma/seed.ts`를 실제 명단 기반으로 바꿔서
`npm run seed`로 다시 채울 수 있습니다.

## 배포하기 (Vercel + Neon Postgres)

1. **Neon 계정 생성 및 DB 만들기** — [neon.tech](https://neon.tech)에서 무료 가입 후
   새 프로젝트를 만들면 `postgresql://...`로 시작하는 연결 문자열을 줍니다.
2. **로컬 `.env` 파일 생성** — 프로젝트 루트에 `.env` 파일을 직접 만들고
   `DATABASE_URL="<Neon 연결 문자열>"`을 넣습니다.
3. **스키마 반영 + 초기 데이터 채우기**
   ```bash
   npx prisma db push
   npm run seed
   ```
4. **GitHub에 코드 올리기** — 로컬 git 저장소는 이미 초기화·커밋되어 있습니다.
   GitHub에서 새 저장소를 만든 뒤:
   ```bash
   git remote add origin <새 저장소 URL>
   git push -u origin main
   ```
5. **Vercel에 배포** — [vercel.com](https://vercel.com)에서 GitHub 저장소를 Import 합니다.
   프로젝트 설정의 **Environment Variables**에 `DATABASE_URL`(Neon 연결 문자열)을 추가하고
   배포하면 끝입니다. (Vercel이 Next.js 프로젝트를 자동으로 인식합니다.)

배포 후에도 관리자 계정(박용운, PIN 0000)과 데모 인원(PIN 1234)으로 바로 테스트할 수
있습니다. 실제 서비스로 전환할 때는 데모 인원을 지우고 `/admin/org`에서 실제 명단으로
교체하세요.

## 보안 참고 (배포 전 꼭 확인)

- `src/lib/auth.ts`의 세션 서명 비밀키(`SESSION_SECRET`)는 개발용 하드코딩 값입니다.
  실제 서비스로 계속 쓸 경우 예측 불가능한 값으로 교체하는 것을 권장합니다.
